Plan for Implementing Authentication Health Check for Tableau Server

The objective is to set up a CloudWatch Synthetics Canary that verifies user authentication to the Tableau server by simulating a login through Cognito SSO and validating successful access to the dashboard. This Proof of Concept (POC) will ensure that the authentication workflow is functioning correctly and provide visibility into potential issues affecting user access.

Implementation:

Configuring CloudWatch Synthetics Canary

Using Python Selenium 4.1 runtime to execute the authentication health check script.

The python script will simulate a user navigating to the Tableau server URL, interacting with the Cognito SSO login page, and verifying access to the authenticated dashboard.

Steps in the Script:

1. Navigate to the Tableau server URL.
2. Detect redirection to the Cognito login page and confirm presence of login fields.
3. Input valid credentials (username and password).
4. Submit the login form and wait for the redirection to the authenticated dashboard.
5. Validate success by checking the final URL for indicators that show that the tableau home page was successfully accessed 

Set Up Canary Configuration

Define Canary properties, including the execution schedule 
Specify environment variables or use AWS Secrets Manager to securely store and retrieve the Tableau server URL and user credentials.
Configure logging and error reporting to detect failures in the authentication workflow.
Test and Validate

Deploy the Canary and run tests to confirm successful execution of the health check script.
Verify logs to ensure proper detection of the Cognito login page, successful form submission, and redirection to the dashboard.
Simulate failure scenarios (e.g., incorrect credentials, server downtime) to validate error handling and notification mechanisms.
Integrate with Monitoring and Alerting

Set up Amazon CloudWatch Alarms to trigger alerts if the Canary detects failures.
Integrate with notification systems (e.g., Amazon SNS or third-party tools) to ensure timely incident response.
This plan ensures that the Canary provides comprehensive insights into the health of the authentication workflow, making it easier to identify and resolve access-related issues for the Tableau server.
