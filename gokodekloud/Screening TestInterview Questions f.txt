7. What is containerization, and how can it be used effectively in the cloud (e.g., using
Docker and Kubernetes)?

Containerization is a method of packaging applicatins into smaller isolated lightweight environments known as containers, this container includes all dependencies required by the application to run. 

Docker creates container images that package application code along with all its dependencies. This is done using a Dockerfile, which defines the container's environment, dependencies, and runtime configuration. Docker also manages the execution of these containers, maintaining consistency across different environments.

In cloud environments, Docker containers can be deployed on container orchestration services such as Amazon ECS (Elastic Container Service), AWS EKS (Elastic Kubernetes service), Azure Container Instances (ACI).

Kubernetes is a container orchestration tool that manages coontainerized applications, kubernetes automates the deployment, scaling, networking, storage and management of containerized applications.

11. Can you explain the process of debugging and troubleshooting a networking issue within a
cloud environment?

Debugging networking issues starts with tracing where the connectivity/communication links may have been faulty, utilizing the observability tools put in place and monitoring VPC flow logs. this includes:

Identifying the Scope of the issue: Determine if the issue affects a single instance, a subnet, or the entire network.
Check Network Logs & Metrics: Use VPC Flow Logs, CloudWatch, or third-party tools to analyze inbound/outbound traffic
Test Connectivity: Run ping to detect latency, packet loss, or misconfigured routes.
Inspect Security group/ firewall Rules: Verify security groups, NACLs, and firewalls to ensure traffic is allowed.
Review Load Balancers & DNS: Check ALB/NLB logs and the DNS services  (Route 53) for any misconfigurations.

13. Explain the concept of a CDN (Content Delivery Network) in the cloud and how it
improves performance.

A CDN is a network of servers all over the world that that cache and serves as off-ramp for internet traffic to deliver content closer to users. It reduces latency by serving the cached content from these edge locations all over the globe, thus,  improving load times and reducing latency significantly.


14. What are the different types of Load Balancers in AWS/Azure/GCP, and when would you
use each?

There are three main types of load balancers:

Application Load Balancer (ALB): Used for HTTP/HTTPS traffic, provides routing based on content and URL paths.

Network Load Balancer (NLB): Used for high-performance TCP/UDP traffic, used for low-latency applications.

Classic Load Balancer (CLB): Legacy load balancer, mainly used for applications that require simple routing.

15. What is a Direct Connect (AWS) or ExpressRoute (Azure), and why would an
organization use it?

AWS Direct Connect and Azure ExpressRoute are dedicated network connections between an on-premises data center and the cloud provider. Their use cases is using them for secure and low-latency connections, while bypassing the public internet.

Example is a cryptocurrency trading platform handling real-time trading, AWS Direct Connect  can be used to  establish a private, low-latency connection between on-premises trading servers and AWS cloud services. This will ensure secure and very fast data transfers, avoiding  delays and eliminating the security risks associated with the public internet.

Reserved instances are instances with long term commitment involved, and this includes a significant of amount saved in cost, It is best suited foir steady workloads that are predictable, it is ideal for production grade applications and databases that are part of long term infrastructure planning.

22. What are cost-saving mechanisms in cloud platforms, such as AWS Savings Plans or
Azure Reserved Instances?

AWS Savings Plans: Provides flexible, discounted pricing in exchange for a period of commitment to a specific amount of compute usage. Unlike Reserved Instances, they apply across multiple instance types, regions, and even other AWS services like Lambda and Fargate.

Azure Reserved Instances: Offer substantial discounts for committing to specific VM instances for a fixed period of one or three years. These reservations help businesses running steady workloads reduce costs compared to pay-as-you-go pricing.

An organization with fluctuating compute needs may benefit from AWS Savings Plans, while one running a consistent set of virtual machines would save more with Azure Reserved Instances
